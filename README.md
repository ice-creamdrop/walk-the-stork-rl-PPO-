# Walk the Stork 강화학습 프로젝트

게임 파일
walkdastork는 인간과의 대결 기능 없이 AI 모델만 학습시키는 코드가 담긴 파일이며, walkdastorkaivshuman은 프레임 지연을 적용하여 인간과 AI를 비교할 수 있게 만든 코드가 담긴 파일입니다.


Python 파일
main.py는 플래시 게임과 Python을 연결하는 역할을 합니다.

train.py는 PPO 알고리즘을 이용해 AI 모델을 학습시킵니다.

draw.py는 학습 데이터를 바탕으로 학습 곡선을 그려 모델의 학습 과정을 확인할 수 있도록 합니다.
